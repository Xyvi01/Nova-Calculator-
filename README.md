# Nova Calculator

A responsive calculator built with HTML, CSS, and vanilla JavaScript.

## Features
- Addition, subtraction, multiplication, and division
- Decimal numbers and sign toggle
- Clear all and delete last digit
- Keyboard support
- Responsive layout for mobile and desktop
- Handles division by zero with an error message

## Run locally
Open `index.html` in a modern web browser. No installation or dependencies are required.

## What I learned
- Structuring a page with HTML
- Styling a responsive interface with CSS Grid
- Handling button and keyboard events in JavaScript
- Using functions and state variables to perform calculations
- Handling edge cases such as division by zero
